Event Outline



In a Score Challenge Event, you will need to challenge Event Set Pieces for your best possible score!


You can earn Event Badges by placing on the High Score leaderboard, or by playing Lives and Minigames during the Event period.

Exchange Badges for items such as Event Memories at the Exchange.



◆Event Memory



Total High Score Ranking



The Total High Score Ranking is based on the combined time-limited scores from all Event Set Pieces!


If you place in the rankings, you'll earn rewards such as Event-exclusive Badges.



* For details, please go to [Event] → [Ranking] → [Total High Score Ranking]



High Score Ranking



The High Score Ranking is a limited-time ranking where players compete for the highest score on each Event Set Piece.


If you place in the rankings, you'll earn event-exclusive Badges.



* Both event-limited and regular scores of Event Set Pieces will be saved.

* For details, please go to [Event] → [Ranking] → [High Score Ranking].

Event Bonus



Event Bonuses include a bonus that increases the amount of Event Badges you earn from Lives.

There are three types of bonuses you can earn in Lives: "Member Bonus", "holomem Bonus", and "Bloom Bonus".


・Member Bonus: Earn more rewards from Live with eligible Members.

・holomem Bonus: Earn more rewards from Lives with eligible holomems.

・Bloom Bonus: Earn more rewards from Live based on assembled Bloom level.



Event Bonuses also include a bonus that increases the amount of Event Badges you earn from Minigames.

There are two types of bonuses you can earn in Minigames: "Minigame Bonus" and "Member Bonus".


・Minigame Bonus: Earn more rewards when playing the eligible Minigames.

・Member Bonus: Earn more rewards just by owning eligible Members.
