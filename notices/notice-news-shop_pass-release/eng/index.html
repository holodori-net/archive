The “HoloPassport” is here with various perks offering, including double rewards for Live & Minigames!



◆HoloPassport

Membership



“Membership” is now being offered. Subscribing to a Membership will earn you "Menshi Medals" which can be use to exchange for Park Outfits and more!

New items that can be obtained using Menshi Medals will be added each month!


◆Membership

Membership is a monthly paid subscription available for each holomem.


You can earn Menshi Medals for each holomem when you join or renew your Membership.

Menshi Medals can be exchanged for items at corresponding Member’s Membership menu.


* For details on Monthly Perks, please go to [Shop] → [Membership] → [Details] icon.
